# DeepSeek Chat Context Management Example

This example demonstrates how to manage conversation context in a client-side chat application. It simulates an AI chat with a predefined turn limit. When the limit is reached, the application preserves the entire conversation history (context) and allows the user to continue the chat by re-sending this full context, simulating a seamless continuation after an interruption.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
